Text and Number Analyzer
📌 Description
This project is a web-based application that analyzes both numerical and textual inputs. It performs operations like checking whether a number is even or odd, determining if it is prime, reversing the number, and analyzing text by counting vowels, changing case, and reversing the text.

🎯 Features
🔢 Number Analysis
Check if a number is Even or Odd
Determine whether a number is Prime
Reverse the given number
🔤 Text Analysis
Count the number of Vowels
Convert text to Uppercase
Convert text to Lowercase
Reverse the input text

🛠️ Technologies Used
HTML – Structure of the application
CSS – Styling and layout
JavaScript – Logic and functionality
